# Night Dragon Screensaver

A fullscreen browser screensaver: desert night sky, moon, drifting dragons, meteors, and a quiet clock.

Open the page, click once for fullscreen, and leave it running on a Mac, TV browser, or phone.

## Live

After GitHub Pages is enabled:

https://tricmagicstick.github.io/night-dragon-screensaver/

## Controls

- Click / tap — fullscreen
- `F` — fullscreen
- `C` — show or hide the clock
- `Space` — pause / resume

Works offline after the first load. No accounts, no trackers, no extra files.

## Use it as a screensaver

**Mac**
1. Open the Pages URL in Safari.
2. Click for fullscreen.
3. Optionally add the page to the Dock or make a Desktop shortcut.

True macOS `.saver` bundles need Xcode. This page is the practical version that works today on the Air, a TV browser, or a phone.

**TV**
Cast the tab, AirPlay Safari, or open the URL in the TV’s browser if it has one.

## Local

Open `index.html` directly. No build step.
